# 시야쥬 재구성 — 웹 서비스 정리 + iOS 표준 UI (iPhone·iPad)

작성: 2026-11-09 · 상태: **사용자 확인 대기 (구현 전)**

## 0. 목표
1. location.b-612.kr **웹 서비스(웹앱·/lab 센서 실험실)를 없앰**. 서버는 앱 전용 API만 남김.
2. 앱을 기능별로 나눔: **타임라인 · 자동 체크인 · 경로 기록 · 설정**.
3. 화면은 iOS 기본 구성 요소와 Apple 인간 인터페이스 지침(HIG)을 따름. iPhone + **iPad 지원 추가**.

## 1. 웹 서비스 정리 (서버)

| 무엇 | 처리 |
|---|---|
| `public/` (index.html·app.js·track.js·mapkit.js·nav.js·lab/·manifest) | 삭제 |
| `tools/` 웹용 시뮬레이터(sim*.mjs·replay.mjs·record_demo.py), `tests/e2e.py`(웹 화면 시험) | 삭제. `tools/daysim`(Swift 하루 기록 시뮬)·`tests/test_autocheckin.py` 는 유지 |
| `location-web` 컨테이너(nginx) | 없앰. NPM 호스트 75 가 `location-api:8000` 으로 바로 전달 |
| tailscale-auth(웹 로그인 보호) | 호스트 75 에서 뺌 — 남는 건 토큰 검사하는 API 뿐 |
| `GET /api/config`(웹 지도 키), `POST /api/log`(센서 원본 녹화) | 삭제 |
| 웹/앱 구분(`X-App-Gate`) | 없앰 → **모든 요청에 Bearer 토큰 필수** |
| 앱 주소 `https://location.b-612.kr/app-api` | **그대로** (FastAPI 가 `/app-api` 접두어로 받음) → 앱 설정 바꿀 필요 없음 |

- 남는 API: tracks(경로 기록) · day(하루 기록 점·머문 곳·이동 방식·걸음) · carplay · autocheckin · health.
- 데일리요섭은 DB(`location_log`)를 직접 읽으므로 영향 없음. `mytrack.py` 설명의 웹 주소만 고침.
- 순서: 앱이 쓰는 경로가 그대로 동작하는지 먼저 시험 → NPM 전환 → 컨테이너·파일 삭제 → README 정리.
- 되돌리기: 정리 전 커밋에 태그 `before-web-removal`.

## 2. 앱 구성

### 2-1. 큰 틀
- **iPhone**: 아래 탭 막대(`TabView`) 4개. 각 탭은 `NavigationStack` + 큰 제목.
- **iPad**: `NavigationSplitView` — 왼쪽 사이드바(같은 4개 항목), 가운데 목록, 오른쪽 지도·상세. 가로·세로 모두.
  (배포 대상 iOS 17 이라 iOS 18 의 `sidebarAdaptable` 대신 크기 등급(horizontalSizeClass)으로 나눔)
- 지금의 강제 다크 모드·직접 만든 색(Palette)·떠 있는 동그란 버튼 대신 **시스템 색·라이트/다크 자동·SF Symbols·Dynamic Type**.
- 기록 중이면 어느 탭에서든 탭 막대 위에 얇은 상태 줄(`safeAreaInset`) — "● 경로 기록 중 · 23분 · 14.2km", 누르면 경로 기록 탭.
  잠금 화면·다이내믹 아일랜드는 **라이브 액티비티**(ActivityKit)로 같은 내용 (3단계).

### 2-2. 탭 1 — 타임라인 (`calendar.day.timeline.left`)
- 제목: 날짜 ("11월 9일 (일)"). 툴바: 이전/다음 날 버튼, 날짜 고르기(`DatePicker` 시트), 오늘로.
- 위: 그날 지도(`Map` + `MapPolyline`; 차=빨강, 도보=초록, 차량 이동(운전 아님)=주황, 추정 구간 점선). 아래로 당기면 접히는 고정 높이.
- 아래: `List` — 머문 곳과 이동이 시간순으로 번갈아.
  - 머문 곳 행: 시각 범위 · 머문 시간 · 장소 이름(자동 체크인 장소면 그 이름, 아니면 '머문 곳').
  - 이동 행: SF Symbol(차 `car.fill` · 운전 `steeringwheel` · 도보 `figure.walk` · 자전거 `bicycle`) · 거리 · 시간 · 걸음.
  - 행을 누르면 지도에서 그 구간 강조 + 상세 시트(`.sheet` + `presentationDetents([.medium, .large])`): 점 수·정확도·출처(GPS/센서 추정/도로 맞춤).
- 맨 위 요약 줄: 오늘 이동 거리 · 걸음 · 운전 시간.
- 지금 상태(머무는 중/운전 1초 기록 중/충전 중 정밀)는 목록 첫 섹션 머리말로.
- 당겨서 새로고침 = 서버에서 그날 다시 받기.
- 기존 '설정 › 하루 종일 기록 › 날짜별 보기 / 하루 지도'를 대체.

### 2-3. 탭 2 — 자동 체크인 (`mappin.and.ellipse`)
- 첫 섹션: 켜기 토글 + 모드 `Picker`(기록만 / 체크인 저장). 저장으로 바꿀 때 `confirmationDialog`.
- '오늘' 섹션: 들어옴·나감 기록. 결과 표시 — 체크인(보냄) / 대기 중 / 무시(이유: "나간 지 9분 만에 다시 들어옴").
  보낼 기록이 있으면 '지금 보내기'.
- '장소' 섹션: 이름 · 반경 · 켜기. 누르면 상세(지도에 반경 원, 반경 `Stepper`/`Slider`, 최근 체크인 시각).
  밀어서 끄기(`swipeActions`). 툴바 `+` → 장소 추가 시트(지금 위치 / 최근 체크인 장소에서 고르기) — 서버 등록이 필요(2단계).
  감시 한도 표시: "장소 감시 6/19 사용 중" (iOS 한도 20, 머묾 감지 1).
- '함께 돌리기' 섹션(기록만 모드일 때만): 날짜별 IFTTT 대비 시각 차이·누락·추가 요약.

### 2-4. 탭 3 — 경로 기록 (`record.circle`)
- 위: 지금 위치·경로 지도(기록 중이면 실시간 선, 속도·방향·GPS 상태 오버레이).
- 아래: 큰 시작/종료 버튼 — `.buttonStyle(.borderedProminent)` + `.controlSize(.large)`, 기록 중이면 빨강 + 종료 확인(`confirmationDialog`). 시작·종료 시 햅틱.
- 이동 수단 `Picker`(segmented): 차 · 도보 · 자전거 · 기타.
- '기록' 섹션: 지난 기록 목록(이름·날짜·거리·시간·데일리요섭 보냄 표시). 자동 운전 기록은 `운전`/`차량 이동` 배지.
  밀어서 삭제·데일리요섭 보내기, 길게 눌러 이름 바꾸기(`contextMenu`). 누르면 기존 경로 상세.
- 지금 '기록 모드'(점 목록 화면)는 기록 상세 안의 '점 목록'으로 옮김.

### 2-5. 탭 4 — 설정 (`gearshape`)
`Form` + 묶음, 각 묶음 아래 설명(footer). 맨 위 상태 요약(오늘 GPS 사용 · 서버 대기 · 마지막 업로드).
1. **자동 기록**(하루 종일 기록): 켜기 · 정확도 단계 · 출발 알아채기(깨워 두기·움직임 감지·GPS 확인 간격·출발 구간 메우기·경계 감지) · 세부(머묾 시간·반경·저장 간격)
2. **배터리**: 절약 · 충전 중 정밀 · 상단 위치 표시
3. **운전·CarPlay**: 차+충전 중 1초 기록 · CarPlay 기록 보내기 · 상태(연결됨/단축어·오디오 경로) · 단축어 설정 방법 링크(`ShareLink` 없이 안내 화면)
4. **쉬는 시간·제외 장소**
5. **서버**: 주소·토큰 · 올리는 간격 · Wi‑Fi에서만 · 지금 올리기 · 기기 보관 기간
6. **권한**: 위치(항상 허용 여부)·동작 및 피트니스 상태 + 설정 앱 열기
7. **정보**: 버전

### 2-6. 이름 정리
- '하루 종일 기록' → **자동 기록** (앱 안에서 '기록'만 쓰지 않음: '경로 기록'(수동)과 '자동 기록'으로만)
- 단축어 동작 이름은 지금 그대로 ('CarPlay 연결 기록하기' / 'CarPlay 연결 해제 기록하기').
- 한자 없이 한글만.

### 2-7. 지키는 것
- 저장된 설정·기록(UserDefaults 키, day/*.jsonl, tracks)은 그대로 읽음 → 업데이트해도 초기화 없음.
- 백그라운드 동작(DayLogger·AutoCheckin·MotionHistory·CarPlay)은 손대지 않음 — 화면만 바꿈.
- 접근성: 모든 아이콘 버튼에 레이블, 큰 글자에서 줄바꿈, 색만으로 구분하지 않음(이동 수단 아이콘 함께).

## 3. 단계

| 단계 | 내용 | 서버 변경 |
|---|---|---|
| 1 | 웹 서비스 정리 (1장) | 있음 (NPM·컨테이너) |
| 2 | 탭/사이드바 뼈대 + 기존 화면 옮기기 + 시스템 색·라이트/다크 + iPad 지원 | 없음 |
| 3 | 타임라인 화면(머문 곳·이동 목록, 이동 수단, 걸음, 도로 맞춤 경로) | 타임라인용 `GET /api/day/{date}` 에 이동 묶음 추가 |
| 4 | 자동 체크인 탭(오늘 결과·무시 이유·장소 상세·장소 추가/반경 수정) | 장소 등록·수정 API |
| 5 | 라이브 액티비티(경로 기록·운전 1초 기록) | 없음 |

각 단계: 리눅스 `swiftc -parse` → GitHub Actions 빌드 → TestFlight. 화면은 시뮬레이터 스크린샷(iPhone·iPad, 라이트·다크)을 CI 에서 떠서 확인 후 보고.

5. 진행: 1→2 먼저 배포, 3~5는 이어서.
